# Sellwane Mosia | Personal Portfolio
 
My personal portfolio, showing the projects I have built, the skills I work with and a bit about me.
 
**Live site:** https://sellwane7.github.io/personalportfolio
 
## Built with
 
HTML, CSS and JavaScript, hosted on GitHub Pages.
 
## Running it locally
 
```bash
git clone https://github.com/sellwane7/personalportfolio.git
cd personalportfolio
```
 
Open `index.html` in your browser, or use a local server such as `python -m http.server 8000`.
